# SmartYT Media Gear

SmartYT Media is a native Gee Gear adapted from the reference SmartYT project.
It keeps the SmartYT core workflow while fitting Gee's Gear platform:

- accept an explicit URL or media search query
- search candidate media without downloading
- sniff media metadata with `yt-dlp`
- download audio, video, or direct image artifacts only after explicit selection

## Runtime Dependencies

The Gear declares these dependencies in `gear.json`:

- `yt-dlp`
- `ffmpeg`
- `ffprobe`

Gee checks the dependencies when the Gear is opened from the Gears catalog. If
Homebrew is available, Gee can install missing `yt-dlp` and `ffmpeg`
dependencies with the registered recipes.

## Data Locations

Job state is written outside the Gear package:

```text
~/Library/Application Support/GeeAgent/gear-data/smartyt.media/jobs/
```

Downloaded media and extracted platform subtitle files default to:

```text
~/Downloads/SmartYT/<job-id>/
```

Agent calls may pass an explicit `output_dir` for download jobs. If no output
directory is specified, Gee uses `~/Downloads/SmartYT`. The Gear package itself
remains copy-installable and should not store user downloads.

## Agent Capabilities

The current Codex-exported acquisition capabilities are:

- `smartyt.search_candidates`
- `smartyt.sniff`
- `smartyt.download`
- `smartyt.download_now`
- `smartyt.get_task`
- `smartyt.list_tasks`

Search returns candidates and task state only. Downloads stay in the SmartYT
task output directory and are not imported into Media Library unless the user
separately asks for import.

The Gear returns structured execution results only. Final user-facing prose must
be generated by the active agent/LLM after the host bridge returns the
structured result.
